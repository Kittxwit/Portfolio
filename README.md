# Portfolio Kittawit

Portfolio website built with Node.js, Vue.js, Vite, and Tailwind CSS.

## How to run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Run the backend server separately:
   ```bash
   npm run dev:server
   ```
4. Run both frontend and backend together:
   ```bash
   npm run dev:all
   ```
5. Build for production:
   ```bash
   npm run build
   ```
6. Preview the production build:
   ```bash
   npm run preview
   ```
7. Or start the Express production server after build:
   ```bash
   npm start
   ```

## Features

- Vue 3 frontend with Vite build system
- Tailwind CSS styling
- Node.js + Express backend serving API endpoints and production build
- Sections for About, Skills, Projects, Resume, and Contact
